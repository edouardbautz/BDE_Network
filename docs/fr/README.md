# Documentation de BDE_Network

BDE_Network est une plateforme libre, à héberger soi-même, pour gérer un Bureau Des Étudiants
(BDE) d'une école du réseau 42. Chaque BDE fait tourner **sa propre instance** : sa base de données, ses
réglages, son application OAuth 42.

Cette documentation est écrite en français et en anglais. Les deux versions disent la même chose.
