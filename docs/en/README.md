# BDE_Network documentation

BDE_Network is a free, self-hosted platform to run a _Bureau Des Étudiants_ (BDE), the student association of a 42
network school. Each BDE runs **its own instance**: its own database, its own settings, its own 42 OAuth
application.

This documentation is written in English and in French. Both versions say the same thing.
